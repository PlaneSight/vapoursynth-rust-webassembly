# Security Policy

## Supported versions

The current `main` branch is supported. This is pre-release software; there are no maintained release branches.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public issue or discussion. Use GitHub's **Report a vulnerability** control on the repository's Security tab to submit a private report.

Include the affected revision, a minimal reproduction, expected and observed behaviour, and an assessment of impact. Reports are acknowledged and handled through GitHub's private advisory flow.
