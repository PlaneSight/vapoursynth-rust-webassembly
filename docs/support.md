# Support

This document is the source of truth for support claims. Evidence comes from the host-native oracle (`tools/build-native-conformance.sh`), the patched Emscripten suites, and the production Playwright corpus in `web/tests/browser/`.

| Area | Status | Evidence |
|---|---|---|
| Raw VapourSynth ABI | Deliberately private | C++ owns the versioned `VSAPI` table and every raw upstream pointer. |
| Upstream core build | Conformant (pinned native oracle + browser) | The native runner builds VapourSynth R79RC1 from `third_party/lock.toml`; CI verifies the manifest before the patched Emscripten build. |
| Standard plugin | Linked (17 common filters) | The static `std` registration exposes the generic filters (Invert, Levels, Median, Minimum, Maximum), the expression evaluator (Expr, scalar-interpreter fallback on wasm), the lookup tables (Lut, Lut2, Lut3), and the simple filters (BlankClip, Crop, AddBorders, flips, turns, Transpose, stacks, ShufflePlanes). See the corpus table below. |
| Python authoring (`.vpy`) | Linked | The synchronous `vapoursynth` package records typed graph plans; the real-Pyodide integration test and the Playwright corpus drive the full Pyodide → RPC → Emscripten → canvas path in the production bundle. |
| Rust-to-upstream validation FFI | Linked | Generation-checked `Core → Node → Frame` token values and typed invocation descriptors cross the C++ bridge; C++ owns all upstream references and releases. |
| Browser worker/canvas | Conformant (corpus only) | Playwright compares native-generated dimensions, SHA-256-addressed RGBA bytes, and normalized failure envelopes through the production Pyodide → RPC → Emscripten → canvas path. |
| Multi-frame output | Linked (bounded RGB24) | Runtime tests cover clip metadata, arbitrary frame selection, cancellation, timing metadata, and deterministic `VideoFrame.close()` ownership; the browser interaction test covers seek/playback through three frames. |
| WebCodecs input | Scoped (bounded RGB24) | Runtime tests cover the adapter's RGBA8/`VideoFrame` copy, timing validation, deterministic input-frame closure, and source-node release; linked native coverage for browser `VideoFrame` uploads remains future work. |
| Native plugin binaries | Unsupported | They must be rebuilt from source. |
| Dynamic plugin discovery | Unsupported | The browser patch explicitly rejects it. |
| `std.Resize` / zimg | Deferred | Not in the linked source closure. |
| Threaded scheduler | Opt-in | `browser_threaded` enables the upstream scheduler with a bounded Emscripten pthread pool; runtime status reports whether isolation and `SharedArrayBuffer` make it usable. The default artifact remains synchronous and single-threaded. |
| WebCodecs media integration | Scoped | Only RGB24 frame transport is implemented; container demuxing/muxing, audio, and broader pixel-format conversion remain separate work. |
| Native-VS differential conformance | Conformant (19 checked-in cases) | 17 RGB24 frame cases and two invocation failures are generated by the host-native oracle; this is not a claim about unlisted formats, plugins, or scheduler behavior. |

## Common filter corpus

Each vector lives once in `native/tests/vectors/` as a plan plus native-generated RGBA8 output where applicable. `conformance.json` records the locked source, native/browser patch boundary, scalar Meson options, RGB24 format, packed RGBA stride, dimensions, hashes, and normalized failures. `generate_corpus.py --check` is read-only; `--refresh` is an explicit developer action with atomic replacement. The Emscripten `render_plan` target and Playwright consume these artifacts; only the latter is the production browser proof.

All 17 frame families and two failure cases pass both native and browser gates. The native build uses the upstream scheduler with one configured worker; the default browser artifact uses the synchronous single-thread scheduler. The opt-in threaded artifact is a separate build and is not covered by this corpus's default CI path.

## Claim vocabulary

- **Scaffolded:** interfaces or ownership boundaries exist, but no upstream execution occurs.
- **Build candidate:** sources, pins, and an automated test are present, but the current commit has not yet earned a successful build result.
- **Linked:** upstream symbols are present and exercised by a passing automated test.
- **Conformant:** output and failure behaviour are compared against a pinned native VapourSynth build.
- **Portable:** works in supported browsers from a clean, documented build.
- **Unsupported:** deliberately rejected with a stable error; never silently approximated.
